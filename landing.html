System Architecture

From the stratosphere to your screen in milliseconds.

01

Satellite Acquisition

The NEO-6M GPS module locks onto orbiting satellites to acquire precise latitude, longitude, and altitude data.

02

Serial Data Processing

The Raspberry Pi reads the raw NMEA sentences via UART (`/dev/serial0`) and parses them using Python.

03

Web Visualization

Flask serves the processed data to a Leaflet.js map and Chart.js dashboard for real-time monitoring.

Hardware Wiring Guide

Connect the NEO-6M Module to the Raspberry Pi GPIO.

NEO-6M Pin Raspberry Pi Pin Description
VCC Pin 2 (5V) Power Supply
GND Pin 6 (GND) Common Ground
TX Pin 10 (RX / GPIO 15) Data Transmit (to Pi)
RX Pin 8 (TX / GPIO 14) Data Receive (from Pi)
