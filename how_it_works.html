System Architecture

From the stratosphere to your screen in milliseconds.

01. Satellite Acquisition

Ang NEO-6M GPS module ay kumukuha ng microwave signals mula sa mga orbiting satellites. Ito ay nagko-compute ng latitude, longitude, at altitude gamit ang trilateration method.

02. Serial Data Processing

Ang Raspberry Pi ay nakikipag-usap sa GPS module gamit ang UART protocol sa /dev/serial0. Binabasa nito ang NMEA sentences (tulad ng $GPGGA) at kinukuha ang kapaki-pakinabang na data.

03. Web Visualization

Ang Flask server ay nagpapadala ng JSON data sa browser. Ang JavaScript (gamit ang Leaflet.js) ay nag-u-update ng mapa at naglalagay ng glowing marker sa totoong lokasyon.
